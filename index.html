The 2020 design assumed signal everywhere.

Some farms of the pilot lie outside coverage, drones fly far from any phone and each collection center starts with no network. The pilot keeps every capability of 2020 and replaces the connectivity premise that no longer holds.

Premise of 2020Design of 2026

Five stops, one history.

Each stop adds an event to the sack, with its date, time and responsible person. Choose a stop to see what the platform records there and what it does while the link is down.

Serverless, because the load is small.

About 11,000 messages a day in harvest, 0.13 a second. Sites at the edge hold their data until a path exists, and AWS receives each event, stores it once and runs a function that ends when its result is written. Between events nothing runs and almost nothing is billed.

    An outage becomes a delay.

    The node writes every reading to flash before its modem powers on, and deletes a record only after the cloud confirms it. Move the length of the outage and see what reaches the platform while a lot dries, with one reading an hour.

    The critical paths, built in 100 hours.

    Terraform builds the pattern of network, security and one environment, the telemetry ingestion path and the inference function. The 200 farms come from one module repeated. Every environment comes from the same code with different variables.
